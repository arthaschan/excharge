## 二、数据结构匹配分析

### 2.1 充电站 vs 光伏电站：根本性差异

| TAIG 计划要求 | 舍得酒业数据实际 |
|-------------|----------------|
| **充电站** 电力数据 | **光伏电站** 逆变器数据 |
| EV 充电功率、充电量、SOC | 光伏输出功率、PV组串电流/电压 |
| 充电桩运行状态 | 逆变器状态 |
| 充电车型/用户行为 | 无 |
| **人工标注的异常标签** | **无标注，只有原始时序值** |

**结论：充电站 ≠ 光伏电站，两个概念在物理上完全不同。**

### 2.2 真正匹配的方向（技术路线层面）

#### 方向 A ⭐⭐⭐ 与 TAIG 计划直接对齐

**光伏逆变器异常检测 + 可解释性分析**

把"充电站"替换成"光伏逆变器"，技术框架完全适用：

| TAIG 计划原版 | 替换版 |
|-------------|--------|
| 充电站网络数据 | 光伏场站 41 台逆变器数据 |
| 充电桩线缆老化、电池衰减、接触不良 | 逆变器组串阴影、组件故障、MPPT 追踪失效 |
| 人工标注异常状态 | 需要人工标注（⚠️ 数据缺失） |
| 有监督时序深度学习模型 | LSTM/Transformer 时序分类模型 |
| **GradCAM 可解释性** | **GradCAM / 特征重要性分析** |

→ 可发 **TAIG 会议**，主题落脚在"新能源电站 AI 透明性与可解释性"

#### 方向 B ⭐⭐ 高度相关（华为 36 路 PV 数据）

**组串级故障检测 + 层级化可解释性**

华为 NB-44/46 有 **36 路 PV 组串电流**，31 天数据。组串间电流差异直接反映阴影/灰尘/故障。

- 有监督分类模型（正常 vs 故障时段）
- **GradCAM 可视化"哪一路组串导致了异常判断"**
- 符合 TAIG 的"透明性 + 前沿领域风险治理"主题

#### 方向 C ⭐⭐ 相关

**逆变器效率异常检测**

- 利用华为 103 列数据中的转换效率、内部温度、有功功率
- 识别效率骤降/异常升高等工况
- 技术路线完全一致，仅下游任务从"充电站"换成"逆变器"

## 三、⚠️ 最大障碍：人工标注问题

TAIG 计划明确要求 **"人工标注为充电站异常状态打时序标签"**，是硬性前提。

### 三种可行路径

| 路径 | 说明 | 可行性 |
|------|------|--------|
| **路径 1：自建标注** | 从舍得酒业现场运维记录中提取历史故障事件，与时序数据对齐后构建标注数据集 | ⭐⭐⭐ 最佳，需确认运维记录存在 |
| **路径 2：华为状态字段弱监督** | 华为 103 列中有「逆变器状态」字段，可作为弱监督标签 | ⭐⭐ 可行，但需验证标签质量 |
| **路径 3：仿真合成** | 无监督异常检测（Isolation Forest / AutoEncoder）作为替代，再补充专家规则验证 | ⭐ 可行，但偏离"有监督"核心要求 |

## 四、假设标注问题已解决：方案设计与数据来源

> 以下假设：**通过舍得酒业运维记录 + 华为逆变器状态字段，可构建出有效标注数据集。**

---

### 4.1 完整研究方案（适配 TAIG 会议）

#### 研究题目（候选）

> **Explainable Anomaly Detection in PV Inverter Networks: A GradCAM-based Interpretability Framework for Renewable Energy Governance**

> 中文候选：**面向新能源治理的光伏逆变器网络可解释异常检测——基于 GradCAM 的透明性分析框架**

#### 研究框架

```
数据层                     模型层                    解释层
─────────────            ────────────              ─────────────
舍得酒业光伏场站           有监督时序分类模型          可解释性分析
41台逆变器 × 31天         LSTM / Transformer        GradCAM
15min粒度                 异常 vs 正常               特征重要性
                            │
标注层                     │                        │
─────────────             ▼                        ▼
运维记录 + 华为状态字段  → 异常标签  ──────────→ 异常判据溯源
（路径1+2组合）           （正常/阴影/故障/衰减）    （哪些特征导致异常）
```

#### 技术路线

**Step 1：数据预处理与特征工程**
- 融合 39 台阳光逆变器 + 2 台华为逆变器数据
- 构造多维特征：输出功率、PV组串电流/电压、转换效率、内部温度、三相不平衡度
- 对齐时间戳（统一 15 分钟粒度）
- 与标注数据集（运维记录）按时间戳匹配

**Step 2：有监督时序分类模型**
- 基础模型：LSTM / Transformer Encoder
- 训练目标：二分类（正常 vs 异常）或四分类（正常 / 组串阴影 / MPPT失效 / 效率衰减）
- 验证方法：k-Fold 交叉验证

**Step 3：GradCAM 可解释性分析**
- 在模型预测异常时，通过 GradCAM 可视化：
  - **时间维度**：哪些时间段导致了异常判断
  - **特征维度**：哪些输入特征（功率/温度/组串电流）权重最高
  - **空间维度**（华为 36 路 PV）：哪一路组串对应异常判断
- 量化分析：统计不同异常类型下，特征重要性的分布差异

**Step 4：TAIG 主题映射**
- 透明性：GradCAM 将"黑箱预测"转化为"可理解的原因"
- 前沿领域风险治理：光伏场站异常如果不及时处理可能导致火灾/设备损毁，AI 可解释性辅助运维决策
- 贡献点：首次将 GradCAM 应用于光伏逆变器网络的透明性分析

#### 数据项 2：异常标注数据 ❌⚠️ 待确认

| 来源 | 内容 | 可行性 |
|------|------|--------|
| 舍得酒业运维记录 | 现场工程师记录的故障事件（时间、设备、类型、处理结果） | ⭐⭐⭐ 最佳，需联系舍得确认 |
| 华为「逆变器状态」字段 | 103 列中的"逆变器状态"，可能包含 正常/待机/故障 状态码 | ⭐⭐ 可作为弱监督标签，需验证准确性 |
| 舍得酒业巡检照片 | 若有光伏组件巡检图像，可与时序数据对齐 | ⭐⭐ 需确认是否存在 |

**推荐策略：路径1+2组合**
- 以华为「逆变器状态」字段为主标签（时间分辨率高）
- 以运维记录为辅，对状态字段进行人工校正和质量验证
- 对无标签时段，标注为"未知"，在训练时处理

#### 数据项 3：气象数据 ❌⚠️ 待获取

| 数据 | 用途 | 获取方式 |
|------|------|---------|
| 水平面辐照度（GHI） | 作为特征输入，提升异常检测准确率 | 中国气象数据网 / 舍得当地气象站 |
| 环境温度 | 与内部温度对比，判断散热异常 | 同上 |
| 云量 / 天气现象 | 区分"天气导致的功率下降"vs"设备故障" | 同上 |

**说明：** 若气象数据无法获取，模型仍可工作（仅用电力特征），但精度会下降。这是**高优先级**的数据补充项。

### 4.3 标注方案设计

#### 标注体系（三级）

| 级别 | 标注类型 | 数据来源 | 说明 |
|------|---------|---------|------|
| L1 | 设备级异常 | 华为「逆变器状态」字段 | 二分类：正常 / 异常（粗粒度） |
| L2 | 工况级异常 | 运维记录 + 领域知识规则 | 四分类：正常 / 组串阴影 / MPPT失效 / 效率衰减 |
| L3 | 组串级异常 | 华为 36 路 PV 电流差异分析 | 精确定位到某一 PV 路（仅华为设备） |

#### 标注流程

```
Step 1：获取华为逆变器状态字段 → 生成 L1 标签（正常/异常二元序列）

Step 2：获取运维记录 → 与 L1 标签交叉验证 → 提升 L1 质量

Step 3：结合领域知识规则（如：效率<85% 且 温度>70°C → 标注为"效率衰减"）→ 生成 L2 标签

Step 4：针对华为 36 路 PV 数据 → 计算各路电流偏差率 →
        偏差>20% → 标注为"组串阴影" → 生成 L3 标签
```

### 4.4 技术实现清单

#### 模型层

| 模块 | 技术选型 | 备注 |
|------|---------|------|
| 时序分类模型 | LSTM / Transformer Encoder / TCN | 对比，选精度最高者 |
| 可解释性 | GradCAM / Attention Visualization | 针对时序数据的 1D GradCAM |
| 基准模型 | Random Forest / XGBoost | 对比深度学习 vs 传统方法 |
| 异常检测（无监督对比） | Isolation Forest / AutoEncoder | 作为 TAIG 中"无监督 vs 有监督"对比实验 |

#### 评估指标

| 指标 | 含义 |
|------|------|
| Accuracy / Precision / Recall / F1 | 分类性能 |
| AUC-ROC | 综合判别能力 |
| **Fidelity** | 可解释性忠实度（解释是否真实反映模型决策）|
| **AOPC**（Average Percentage Point Change） | GradCAM 质量评估标准 |
| 专家满意度评分 | 邀请 3~5 位电力行业专家，对 GradCAM 输出进行可信度打分（1~5 分）|

#### TAIG 论文贡献点

1. **数据贡献**：首个融合光伏逆变器多维电力特征与 GradCAM 可解释性分析的公开数据集（舍得酒业，标注版）
2. **方法贡献**：提出针对光伏时序数据的层级化可解释异常检测框架（L1→L2→L3）
3. **应用贡献**：将 AI 治理的透明性原则落地到新能源电站运维场景
