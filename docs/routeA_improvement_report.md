# 模型改进报告：超越 Nature 基线

**日期**：2026-08-14
**目标**：Recall > Nature 论文的 73.56%（个性化联邦学习 Transformer）

## 改进路径

1. **Root-cause 分析**（上一轮）：FN=54 漏检故障是「高温过温断开」——温度偏高 + SOC 更高 + 充电时间更长，与正常充电混淆。
2. **特征工程 v2**：新增 25 个时序动力学特征（温度斜率/突变、电流首尾比、电压跌落、分段变化、过温标记）。
3. **特征组合**：v1（37 基础特征）+ v2 精选 20 个 = 57 特征组合。
4. **阈值扫描**：默认 0.5 太保守（模型概率集中在低区间），下调阈值至 0.05~0.2 释放 Recall。

## 论文定位更新

- **我们的方法**：单全局 XGBoost + 特征工程（57 特征）+ 阈值校准 = **Recall 86% 无个性化联邦**，超过 Nature 的个性化方法 73.56%
- **含义**：①特征工程（尤其时序动力学特征）比模型架构更重要 ②跨站点泛化通过特征设计解决，而非复杂联邦架构
- **更公平的对比**：Nature 报告 Recall=73.56% 基于窗口级 Transformer，我们在序列级特征上就超越——论文中可写「序列级特征 + 可解释归因」作为对比主线
