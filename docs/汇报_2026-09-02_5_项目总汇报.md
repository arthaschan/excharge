# excharge 项目总汇报（供导师/论文组决策，2026-09-02 夜）

> 任务：深圳 30 座充电站跨站点异常检测（owner1-6 训练 → owner7-8 测试，2776 序列 / 129 故障）。
> 口径：62 维手工特征 + 6 通道时序；主指标 **PR-AUC**（阈值无关），辅以 AUC / 校准 F1。
> 环境：NVIDIA H100 / torch 2.6.0+cu124。本文档合并前两批全部实验结果，作为论文路线决策依据。

---

## 一、一句话结论

**本任务上，性能排序：TabPFN-2.5 (0.964) > Token-Attn 集成 (0.918) > XGBoost (0.887) > LightGBM (0.868)。两个深度模型都显著超越 GBDT，"深度打不过 GBDT"彻底证伪。** 差异在于：TabPFN 用同样的 62 维特征拿到全场最高分但牺牲时序叙事与校准（可事后校准补救）；Token-Attn 提供端到端时序 + 双轨可解释性但性能低 0.045。**根因是"瓶颈在分类器，不在特征"**（P0c+P0d 两把尺子联合证明）。

## 三、三条论文路线（老师来选，证据都备齐了）

### R1 —— 纯 TabPFN（性能最优）
- **主模型**：TabPFN-2.5（深度 Transformer 表格基础模型，非树，满足"换深度模型"要求）。
- **性能**：PR-AUC 0.9637（3-seed 集成，0.9623±0.0035），全场最高。
- **可解释性**：弱（in-context 黑盒）；需靠 SHAP/置换重要性事后归因，且无时序叙事。
- **风险**：① 不吃原始时序，给不了"端到端深度时序 + GradCAM"故事；② 概率过度自信（ECE 0.0435），**但已实测可用 Platt 缩放校准到 ECE 0.0067**（Brier 0.017→0.0066），EU AI Act 隐患可控。

### R2 —— 纯 Token-Attn（可解释性最优，原主线）
- **主模型**：Token-Attn 多模态交互融合（BiLSTM 8 段 token + 62 特征 token + [CLS] 联合 self-attention，~22.4 万参数）。
- **性能**：PR-AUC 0.9184（7-seed 集成），仍显著超 LightGBM（p=0.026）、超 XGBoost。
- **可解释性（双轨 + 消融，GBDT/TabPFN 都给不出）**：
  1. 注意力图 4 张（`docs/tokenattn_attn_figs/`）：异常时模型把注意力从充电启动段"塌缩"向中后段漂移，且更依赖特征 token；最热特征 `a_first_last_ratio / a_seg3_max / t1_max_jump / v_last3_vs_first3`。
  2. 特征组消融（P0e）：移除 32 基础统计量模型崩塌（−0.61），分段差分 −0.16、温度变化 −0.12、电池类型 −0.10、超温标志 −0.03。
  3. 方法论贡献：断点续训 bug + BN 泄露两个坑（对论文严谨性有直接价值）。
- **风险**：性能低于 TabPFN 0.045。

### R3 —— 双模型叙事（推荐考虑）
- **写法**：Token-Attn 为主模型（可解释 + 合规主线），TabPFN 作"该任务表格信号天花板"的 SOTA 参照。
- **核心卖点**：① 可解释深度模型(0.918)逼近表格基础模型天花板(0.964)，两者都远超 GBDT；② 我们主动用可解释性换取可控的 0.045 性能差，并证明 TabPFN 可校准后同样合规；③ 坐实方法论发现"**瓶颈在分类器不在特征**"。
- **风险**：篇幅/叙事复杂度略增，但证据已全部备齐。

## 四、关键方法论发现（可写进论文，有实验支撑）

1. **"深度打不过 GBDT"是假象**：Mac(MPS) 上 3-seed 0.866 被低估；H100 上 Token-Attn 7-seed 集成 0.918 显著超 GBDT；TabPFN 更到 0.964。
2. **瓶颈在分类器，不在特征**：P0c 证明"给 LightGBM 加新特征几乎无用(+0.009)"，P0d 证明"同样的 62 维特征，换 TabPFN 分类器就到 0.964"——两把尺子一合，定位到分类器。
3. **seed 集成对深度模型收益巨大**：Token-Attn 单 seed 0.874 → 7-seed 集成 0.918（+0.045）；而 TabPFN 本身方差极小（std 0.0035），集成收益近乎零。
4. **数据增强三条路全部证伪**：单纯增强(P1a)、残差化(P1b)、分解+增强组合(P1c，导师综述 U-Net-DeWA 逻辑)在"62 特征主导的监督分类"场景均无增益，反而扰动训练动态。
