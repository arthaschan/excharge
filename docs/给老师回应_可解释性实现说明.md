# 给老师回应：可解释性异常检测的实现说明

> 日期：2026-09-03
> 背景：老师对 TAIG 摘要的三点评价，其中第 2 点是"你目前没有实现出基于模型可解释性分析的异常检测的结果，没有实现这个 workshop 的目标"。
> 本文件用于：① 向老师解释我们到底实现了什么；② 明确我们与老师期望之间的差距；③ 给出可直接使用的回应口径。

---

## 一、先分清一个词（这是回应的关键）

- **「可解释的异常检测」**（explainable detection）= 先做检测，再事后解释模型为什么这么判 → **我们做了这个**。
- **「基于可解释性分析的异常检测」**（interpretability-driven detection）= 用可解释性反过来产生/改进检测结果（把归因结果当特征增强 / 新模型模块 / 自监督信号）→ **我们还没做，这正是老师第 3 点建议的方向**。

老师说"没实现 workshop 目标"，指的是后者——我们目前的可解释性是"附录（post-hoc）"，不是"方法本体"。这个判断是对的，应当承认，不应回避。

---

## 二、我们确实实现了可解释性分析（post-hoc），且都是真实实验、有数值

不是 LLM 套话，四块都有实测支撑：

1. **自注意力归因（§4.3）**
   取 Token-Attn 最后一层 [CLS] 的注意力分布，回答"哪个特征 token 在关注哪段充电进程"。
   实测：异常时 [CLS] 对特征 token 的关注从 0.725 → 0.782（模型更依赖特征分支）；
   注意力峰值从启动段(2/8)向中后段(5/8 后)漂移——即"异常信号藏在充电中后段"。

2. **置换特征重要性（§4.3）**
   逐特征打乱该列 3 次、观测 PR-AUC 下降（模型无关归因，n=3，随机种子 0，可复现）。
   Top-5 全是枪温统计量：t2_max 0.488±0.020、t1_mean 0.426±0.013、t2_last 0.243±0.028、
   t2_mean 0.237±0.011、t1_last 0.158±0.010。

3. **特征组消融（§4.3）**
   逐组移除 5 类特征重训。移除 32 维基础统计量 → PR-AUC 从 0.916 崩到 0.303（−0.61），
   证明基础统计量是主信号；其余四组移除后仍保持一定性能，说明特征组间存在冗余与交互。

4. **成因机制分析（§4.5）**
   把相关性升级为机制，每条结论都有实测来源：
   - 故障分型：129 个故障按枪温 t_max>55°C 实测分为电气中断型 95.3% / 超温型 4.7%；
   - 终止方式：末端功率占峰值 98%（故障）vs 24%（正常），证明"高功率未衰减的异常终止"；
   - 温度角色：温度-时长弱相关 r≈0.13，证明"温度是充电时长的伴随结果，而非中断原因"。

## 三、给老师的话（可直接用）

> "我们目前做的是『可解释的异常检测』：三路归因（自注意力 / 置换重要性 / 特征组消融）交叉印证
> + 成因机制分析，回答『模型为什么判为异常』，服务 EU AI Act 的透明度与审计，且每一结论都有
> 实测数值。您说的『基于可解释性分析的检测』——把归因结果反哺进模型（特征增强 / 新模块 / 自监督）
> 来进一步提升效果——确实还没做，这正是我们下一步、也是能冲期刊的增量方向。我们已单独写了方案
> （docs/期刊升级方案_可解释性反哺检测.md，含方案 A/B/C 与判据）。workshop 这一版先投
> 『可解释检测 + 合规』。"

这样既承认了差距、又摆出了真实工作量，还接住了老师第 3 点的橄榄枝。
