## 1. 背景：为什么充电站异常检测是"高风险系统"

欧盟《人工智能法案》（Regulation (EU) 2024/1689，2024年8月生效）建立**基于风险的 AI 分类体系**：

- **不可接受风险**（第 5 条）：社会评分等 → 禁止
- **高风险**（第 6 条 + 附录 III）：**关键基础设施**（能源、交通、电网）、医疗、执法、招聘等 → 严格义务
- **有限风险**：聊天机器人等 → 透明度义务
- **最低风险**：游戏滤镜等 → 无强制

**充电站/电网异常检测**属于"关键基础设施安全组件"——按附录 III 第 2 类（关键基础设施的管理与运行）归入**高风险**。部署此类系统需满足 7 项核心义务，且**具有域外效力**（影响欧盟用户即适用）。

## 4. 审计日志模板（EU AI Act 第 12 条）

每次预测自动生成一条不可篡改记录：

| 字段 | 示例 | 用途 |
|------|------|------|
| timestamp | 2026-08-14T12:15:03+08:00 | 决策时间 |
| station_id / pile_id | SZ-07 / P-1024 | 定位设备 |
| transaction_id | tx_884213 | 关联充电事务 |
| raw_features (hash) | sha256:7f3a... | 输入可复验 |
| prediction | fault (class=过温保护) | 决策 |
| confidence | 0.92 | 置信度 |
| **attribution** | t2_max_jump:+12.4, soc_last:-8.2, v_min:-3.1 | 解释（SHAP 值） |
| threshold_used | 0.075 | 操作点 |
| human_action | confirmed / rejected / escalated | 人类监督结果 |
| reviewer | 运维工程师 L. Wang | 责任人 |

**设计要点**：
- 归因值随预测一起存档 → 事后监管审查可回答"**为什么当时判定故障**"
- 人工确认结果回流 → 形成持续学习闭环，同时满足第 14 条
- 特征哈希保证输入完整性 → 可审计性

## 5. Model Card（充电站异常检测器 v2）

```
│ Model Card: 充电站异常检测器 v2                        │

```
