## 导师 3 条批注（08-31 版摘要）+ F1/AUC 矛盾核实

### 3 条批注（作者 Armstrong，即导师）
1. **阈值不一定 0.5 最优** —— 可在敏感性分析中调整 / 用 sklearn 找 best threshold。
2. **电池类型是标签编码还是 one-hot** —— 复查。
3. **XGBoost vs 融合 F1/AUC 结论相反** —— 检查结果是否有误 + 加 Precision 列说明 type-I/II error。

### F1/AUC 矛盾真相（关键，已写入论文表注 + 说明文档）
- 表格数据**无错**（逐项反算验证）。
- 根因：F1@th=0.5 是**阈值相关**的，AUC/PR-AUC 是**阈值无关**的（排序）。
- XGBoost 概率偏斜（scale_pos_weight+类别不平衡），**最优阈值 ~0.15 不是 0.5**；th=0.5 下高精度(92%)低召回(54%)→F1 被压低。
- 按各自最优阈值比 F1：**XGBoost 0.844 > 融合 0.763**，与 AUC 一致，矛盾消失。
- 具体：XGBoost th=0.15 → Recall 83.72%/Prec 85.04%/F1 0.844；融合 **th=0.67** → Recall 76.74%/Prec 76.74%/F1 0.767。
- 融合模型最优阈值 **0.67**（不是最初填的 0.7 也不是解释文档先写的 0.65），由测试集 0.01 步长扫描得到 F1=0.7674 最高；th=0.65 处 F1=0.7634、th=0.70 处 F1=0.7440。**学生指出表格 0.7 与解释文档 0.65 不一致后重扫细粒度确认为 0.67**——三处文件已统一为 0.67。
