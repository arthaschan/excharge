# excharge 项目日志 2026-08-28

## 融合方案（Bi-LSTM + 手工特征）已跑通

### 背景
- 接手交接后，用户拍板走「融合方案」：Bi-LSTM 128维序列表示 + 62维手工特征拼接（原文档写 57 维，实测 **62 维**）。
- **62 维准确拆分（按代码逐 key 计数）= 32 基础统计 + 13 一阶差分/导数 + 8 分段均值/端点 + 4 超温指示 + 5 电池类型**。⚠️ 摘要/旧文档的"37 维统计 + 20 维时序动力学"是错误拆分（37 应为 32，20 应为 21），已修正 paper §3.2 + 融合版摘要 docx。
- 数据口径：owner1-6 训练（13,505/642 故障，内部 80/20 val）、owner7-8 测试（2,776/129 故障），seed=42。

### 关键产物（data/real/fusion_data.pkl + docs/fusion_*）
- **融合模型（单网络拼接）**：PR-AUC **0.748**、F1 0.704、Recall 0.822、Prec 0.616、AUC 0.978（最佳 epoch24）。
- 对比纯 BiLSTM（routeC）：PR-AUC 0.351→0.748（**+0.397，2.1倍**）、F1 0.359→0.704。
- **XGBoost（62维特征，owner1-6 同口径）**：PR-AUC **0.894**（Recall 0.543）。← 这才是《方法路线建议》"0.86–0.89 目标"的真实来源。
- 后期集成（BiLSTM+XGBoost 概率加权 α=0.5）：PR-AUC 0.878、F1 0.798、Recall 0.736。

### 诚实结论（重要）
单网络融合到 0.748，**没到 0.86–0.89**——该目标其实是 XGBoost 特征的成绩，神经网络头对表格特征利用不如树模型。要到 0.88+ 必须把 XGBoost 拼回来（集成）。

### 双轨可解释性
- 序列分支 1D-GradCAM：融合后枪温排前（GunTemp1 0.47/GunTemp2 0.40），电压反而靠后——电气信息已被 62 维特征吸收。
- 特征分支 TreeSHAP：t2_mean/t2_max/t1_mean/v_min/a_min/soc_last 领先。
- 敏感性：零化任一序列通道 Recall 几乎不变（纯 BiLSTM 里电压置零暴跌 38pp），证明特征主导。

### 「优化融合头冲0.80+」路径已测，结论：纯深度封顶 ~0.75
- 融合 V2（特征分支独立 MLP 62→128→64 + 序列投影）：PR-AUC 0.738、F1 0.658、Prec 0.80、Recall 0.558（epoch26 最佳，val_f1 0.7675）。与 V1 打平，只是用 Recall 换 Precision，PR-AUC 没涨。
- 纯特征 MLP（去掉 BiLSTM）：PR-AUC 0.557。→ 序列分支对融合贡献很大（0.557→0.748）。
- **根因**：树模型在这些表格特征上远强于神经网络（XGBoost 0.894 vs MLP 0.557）。0.80+ 纯深度不现实，除非上 TabNet/FT-Transformer（高成本、不确定）。
