## C1/C2 探索：强化深度融合 + 注意力交互融合

**背景**：三方向实验（A重建式/B域自适应/C GBDT）均无突破后，用户拍板继续做 C1（深度融合加固）和 C2（注意力交互融合，方法创新），多做探索。

**C2 目标**：实现真正的「序列 × 特征」交互融合（非简单拼接），形成论文方法贡献点。三种变体：
- Cross-Attention（特征当 query，查阅序列时间段）
- Gated Fusion（序列/特征互相门控）
- Token-Attn（序列分段池化成 token + 特征 token 联合 self-attention，多模态 Transformer）

**脚本**：`scripts/train_c1c2.py`（统一框架：加权CE + AdamW + cosine + 30 epoch，无断点续训；支持 ONLY/EPOCHS/BATCH/DEVICE 环境变量；结果写 `docs/c1c2_compare.json`）。

## 又一个坑：BatchNorm1d 的 batch=1 报错

- `train_c1c2.py` 的 `FeatMLP` 用 `BatchNorm1d`，训练模式要求 batch≥2。
- 训练集 13505 样本，`BATCH=64` 时最后一批只剩 1 个（13505=211×64+1），BatchNorm 报 `Expected more than 1 value per channel` 直接崩溃。
- 之前 BATCH=128/256 余数都>1，从没触发；这次降 batch 才暴露。
- **修复**：训练循环里加 `if len(idx) < 2: continue` 跳过最后单样本 batch（已改）。
- 教训：凡是含 BatchNorm 的训练脚本，降 batch 前先算 `N_train % BATCH` 是否落在 1；要么跳过单样本 batch，要么换 LayerNorm。

**注意力图脚本首跑前发现 1 个 PyTorch 2.x 兼容 bug**（重要！新写 hook 脚本必读）：
- `nn.TransformerEncoderLayer` 内部调用 `self_attn` 时传 `need_weights=False` → MHA 返回 `(out, None)`，**直接 `register_forward_hook` 抓 out[1] 拿 None 会崩**。
- 解决：**monkey-patch 实例 forward**，强制 `need_weights=True, average_attn_weights=False`（返回 `[B,H,S,S]`）。TransformerEncoderLayer 内部取 `out[0]` 不受影响。
- 已用探针脚本验证：torch 2.12.1、`layer.self_attn` 属性存在（无 `_sa_module`）、`need_weights=True` 返回 (out, [B,H,S,S])、`need_weights=False` 返回 (out, None)。
- 脚本 `make_tokenattn_attn_figures.py` 已改用 monkey-patch 方案，4 张图全部成功生成于 `docs/tokenattn_attn_figs/`。
