> 本文件夹是"期刊论文"方向的唯一主目录。**从 2026-09-04 起，期刊论文的研究、文档、代码、汇报全部放这里**，不再散落到仓库根目录或 `docs/`。
> 方法论母本：《模型选型判定手册 v1.1》（仓库根目录，跨项目通用，不搬入本夹）。

---

## 一、目录结构约定

```
journal/
├── README.md                    # 本文件：总目录 + 结构约定 + 每次汇报一个文档的约定
├── docs/                        # 期刊文档（方案、选题论证、文献综述、实验报告…）
├── code/                        # 期刊代码（build / train / eval / 归因 / 反哺实验…）
└── reports/                     # 汇报文档（每次一个，命名 汇报_YYYY-MM-DD_主题.md）
```

| 子目录 | 放什么 | 命名约定 |
|--------|--------|---------|
| `docs/` | 方案、论证、报告、综述等 markdown | `主题_版本/日期.md`，中文名 |
| `code/` | 可执行脚本、训练/评估/归因代码 | 与 `earlywarning/code/` 同风格，见下 |
| `reports/` | **每次工作会话的汇报**（每次一个文档） | `汇报_YYYY-MM-DD_一句话主题.md` |

---

## 二、"每次汇报一个文档"的约定（重要）

- 每次向老师/团队汇报或每完成一个工作阶段，都在 `reports/` 落一篇**独立、自包含**的汇报文档，方便随时翻查。
- 汇报文档必须包含：① 本次做了什么；② 关键结论/数字；③ 产出文件清单（含路径）；④ 待拍板事项；⑤ 下一步。
- 汇报只做"结果速览"，细节指向 `docs/` 与 `code/` 里的实体文件，不在汇报里堆长文。

---

## 三、代码规范（沿用 earlywarning 纪律）

- 探路阶段 Mac MPS 单 seed 看方向；量产阶段 H100 多 seed（≥5）概率集成看绝对分（手册 R9/F）。
- 每个实验落盘元数据：seed / 环境 / 特征版本 / 切分 / 协议 / 耗时（手册 E7）。
- 反哺实验必须 paired 对照（手册 E10）；前缀任务严守 E11 泄漏自检。
- 脚本用环境变量（ONLY/BATCH/EPOCHS/SEED/DEVICE）控制，参考 `earlywarning/code/train_prefix_tokenattn.py` 风格。
